# 🦺 현장 안전 판독

작업 현장 사진을 올리면 **산업안전보건기준에 관한 규칙** 위반 여부를 판독하고,
위반이 있으면 `위험요인 명칭 / 관련 법령 조항(본문) / 즉시 조치 사항`을 카드로 보여 주는
모바일용 웹 앱입니다. (Python Streamlit + OpenAI API)

## 판독 방식 — 3단계 순차 필터

| 단계 | 하는 일 | 종료 조건 |
|---|---|---|
| 1단계 | 작업이 진행 중인 사진인지 판별 | 비작업 사진 → **[해당없음]** |
| 2단계 | 사진에서 눈으로 확인되는 명백한 위반만 검증 | 위반 없음 → **[위험요소 없음/안전수칙 준수]** |
| 3단계 | 조문 확정 + 즉시 조치 사항 작성 | 2단계에서 확정된 위반만 대상 |

- 단계마다 별도의 API 호출이고, 다음 단계로 넘어갈지는 AI가 아니라 **코드**(`analyzer.py`)가 결정합니다.
- 3단계에는 사진을 주지 않으므로 새 위험요인을 만들어 낼 수 없습니다.
- 조문 본문은 AI가 쓰지 않습니다. AI는 조문 **번호**만 고르고, 화면에는
  `data/law_db.json`(국가법령정보센터 원문, 669개 조문)의 내용이 그대로 표시됩니다.
  존재하지 않는 조문 번호는 자동으로 버려집니다.

### 감독자가 직접 추가하는 위험요인

사진만으로 판단할 수 없어 판정에서 제외된 항목(안전대 체결 여부, 신호수 배치 등)은 결과 아래에 체크박스로 나옵니다.
현장에서 직접 확인해 위반이 맞는 항목을 체크하고 **위험요인으로 추가**를 누르면, 그 항목에 대해 3단계(조문·조치 사항)만
실행해 카드로 추가합니다. 이렇게 추가된 카드는 "감독자 현장 확인으로 추가"라고 표시되어 AI 판정과 구분됩니다.

## 파일 구성

| 파일 | 내용 |
|---|---|
| `app.py` | 화면(사진 입력, 이미지 압축, 결과 카드) |
| `analyzer.py` | 3단계 판독 파이프라인과 프롬프트 |
| `law.py` | 조문 DB 조회 |
| `demo.py` | 데모 모드용 예시 결과 |
| `data/law_db.json` | 산업안전보건기준에 관한 규칙 조문 DB |
| `scripts/build_law_db.py` | 법령 개정 시 조문 DB를 다시 만드는 스크립트 |

## PC에서 실행

```bash
pip install -r requirements.txt
```

```bash
cp .streamlit/secrets.toml.example .streamlit/secrets.toml
```

`.streamlit/secrets.toml`에 OpenAI API 키와 접속 비밀번호를 적은 뒤 실행합니다.

```bash
streamlit run app.py
```

## 휴대폰에서 쓰기 (Streamlit Community Cloud 무료 배포)

1. <https://share.streamlit.io> 에 GitHub 계정으로 로그인합니다.
2. **Create app** → 이 저장소와 브랜치를 고르고 Main file path에 `app.py`를 입력합니다.
3. **Advanced settings → Secrets**에 아래 내용을 붙여 넣습니다.

   ```toml
   OPENAI_API_KEY = "sk-..."
   APP_PASSWORD = "원하는-비밀번호"
   ```

4. 배포가 끝나면 나오는 주소를 휴대폰 브라우저로 열고 **홈 화면에 추가**하면 앱처럼 쓸 수 있습니다.

> 배포 주소는 누구나 접속할 수 있으므로 `APP_PASSWORD`를 꼭 설정하세요.
> 설정하지 않으면 주소를 아는 사람이 내 API 요금으로 앱을 쓸 수 있습니다.

## 결제 전에 써 보기 (데모 모드)

OpenAI 키를 넣지 않고 앱을 열면 **데모 모드** 스위치가 나옵니다. 켜면 키 없이 촬영·업로드·이미지 압축·결과 카드 화면을
휴대폰에서 확인할 수 있습니다. 데모 결과는 올린 사진과 무관한 고정 예시이고, 실제 판독은 API 키가 있어야 합니다.

## 설정값 (secrets 또는 환경변수)

| 이름 | 필수 | 설명 |
|---|---|---|
| `OPENAI_API_KEY` | ✅ | OpenAI API 키 |
| `APP_PASSWORD` | 권장 | 앱 접속 비밀번호 |
| `OPENAI_MODEL` | 선택 | 사용할 모델명 (기본값은 `app.py`의 `DEFAULT_MODEL`) |
| `OPENAI_MODEL_FAST` | 선택 | 조문 후보 선정에만 쓸 더 빠른 모델 |
| `OPENAI_BASE_URL` | 선택 | OpenAI 호환 API를 쓰는 다른 서비스 주소 |

모델명과 전송 이미지 크기는 앱 왼쪽 위 `>` 메뉴에서도 바꿀 수 있습니다.

## 법령이 개정되면

```bash
python scripts/build_law_db.py
```

최신 원문을 내려받아 `data/law_db.json`을 다시 만듭니다. 현재 DB의 시행일은 앱 왼쪽 메뉴에 표시됩니다.

## 유의사항

- AI 판독은 감독 업무를 돕는 보조 수단입니다. 사진에 찍히지 않은 상황(화면 밖 화재감시자, 작업허가서 등)은
  반영되지 않으며, 이런 항목은 위반으로 판정하지 않고 "사진만으로 판단할 수 없는 항목"으로 따로 보여 줍니다.
- 참고 KOSHA Guide는 AI가 기억으로 제시하는 지침명이라 검증된 정보가 아닙니다. 화면에도 그렇게 표시됩니다.
- 사진은 판독을 위해 OpenAI 서버로 전송됩니다. 사내 보안 규정상 현장 사진의 외부 전송이 가능한지 확인하세요.
